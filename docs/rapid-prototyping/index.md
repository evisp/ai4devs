## Learning objectives

### UI Mockup from Text

By the end of this project, you'll be able to:

- Turn plain-language product ideas into structured UI mockups
- Define screens, layouts, and user flows clearly
- Describe interface elements developers and designers can act on
- Refine rough concepts before visual design begins
- Spot usability gaps early in the planning stage

### API Prototyper

By the end of this project, you'll be able to:

- Turn feature ideas into clear API endpoint plans
- Define inputs, outputs, and core data models
- Create prototype-ready request and response structures
- Validate API logic before full implementation starts
- Improve consistency across services and integrations

!!! tip
    For both projects, review the output for clarity, completeness, and real-world usability before moving forward.

!!! warning
    Never skip review—unclear UI plans create friction, and weak API designs create expensive rework.
