## 📖 How to use this material

!!! tip "The Three Deliverables"
    For every project in these blocks, aim to produce:
    1. **A Clear Deliverable**: The actual code, schema, or app.
    2. **A Prompt Log**: A history of what you tried, what failed, and why.
    3. **The Proof**: Tests, logs, or screenshots that prove the output is correct.

!!! warning "Verification over Generation"
    AI output is a starting point, not a finished product. Always verify results with repeatable checks. In this course, **"Because the AI said so" is never a valid answer.**
