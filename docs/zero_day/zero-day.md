# Zero Day: Essential Setup for AI4Devs

This guide helps you set up the accounts and tools you need for AI4Devs at Holberton. You’ll confirm platform access, join the communication space, set up GitHub for submissions, and launch your development environment so you’re ready to start building.

## Why this matters

Starting the program without setup usually means you lose time on day one: you can’t access project specs, you miss important messages, or you can’t push your work when it’s time to submit.

![Zero day](https://i.imgur.com/4VGN8Y2.png)


## Step-by-step setup

### 1. Access and configure the Holberton intranet

The intranet is your home base for project instructions, deadlines, and progress.

- Go to: https://intranet.hbtn.io/
- Log in with the credentials sent to you by email
- Bookmark it (you’ll use it daily)

**Complete your profile**

- Click your profile icon (bottom-left area)
- Fill in all required fields marked with `*`
- Add a professional profile photo
- Save changes
- For now: don’t change your password unless your staff explicitly asks you to

!!! tip
    Add your GitHub username to your intranet profile as soon as you create it.
    Small detail, big time-saver later.


### 2. Create (or confirm) your GitHub account

GitHub is where your repositories live. It’s also how you’ll share work and collaborate.

If you already have an account, you can keep using it—just make sure it’s professional.

If you need a new account:

- Sign up: https://github.com/signup
- Pick a username you’d be comfortable putting on a resume

A good username is simple, readable, and something you won’t be embarrassed to share later.

!!! warning
    Don’t use a throwaway email you won’t have access to in 6 months.
    You’ll need this account long-term.


### 3. Launch your cloud development environment (COD)

COD gives you a ready-to-use Linux environment so everyone works in a consistent setup.

- Go to: https://cod.hbtn.io/sign_in
- Log in using the same credentials as your intranet (if that’s how your cohort is configured)
- Wait for the dashboard to load

**Select your region**

- Choose **Europe** (best performance for your location and cohort setup)

**Start the right container**

- Select the container recommended by your cohort (example: `ubuntu_2204`)
- Click **Spin Up Container**
- Wait for it to start (often 30–60 seconds)

**Open VS Code**

- Click **Actions → VS Code** to open the browser-based editor

!!! note
    COD sessions can expire after a few hours.
    Plan to save your work often and push to GitHub so nothing is lost.

## Quick daily reference

| Tool | Where | What it’s for |
|---|---|---|
| Holberton intranet | `intranet.hbtn.io` | Projects, requirements, deadlines, progress |
| GitHub | `github.com` | Repositories, submissions, collaboration |
| COD | `cod.hbtn.io` | Linux environment + VS Code in the browser |
