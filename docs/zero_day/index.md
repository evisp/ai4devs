# Tools Overview

These tools help you work faster, stay organized, and avoid losing progress.

![Tools](https://i.imgur.com/s1bZ4Mw.png)

## [Zero Day Set Up](./zero-day.md)

**Get ready for day one**

Set up your accounts, access to the learning platform, communication channels, GitHub, and your development environment so you can start projects immediately.

What you’ll do:

- Confirm access to the Holberton platform and required services
- Set up your workspace (folders, editor, terminal)
- Verify everything works with a quick checklist

## [Git and GitHub](./git-and-github.md)

**Save your work and collaborate**

Git is your safety net. It keeps a history of your changes so you can recover from mistakes, work in steps, and share your work on GitHub.

You’ll learn:

- The daily workflow: edit → stage → commit → push
- How to sync changes with others (pull/push) without chaos
- How to fix common issues (wrong branch, conflicts, authentication)

## [VS Code Setup](./vscode-setup.md)

**Your coding workspace**

VS Code is where you’ll read code, write code, run commands, debug problems, and manage projects in one place.

You’ll learn:

- A clean setup that works well for project-based work
- How to run and debug code from the editor
- Useful extensions and settings (formatting, linting, Git integration)

!!! tip
    Start here: these three tools work together.
    VS Code is your workspace, GitHub is where your work lives online, and Git is what keeps your progress safe.
