# Code Generation Analysis


Use AI to understand, modernize, and translate code across contexts—turning complex or unfamiliar codebases into opportunities for learning and improvement.


!!! note
    In this block, you will build two practical skills: (1) using AI tools to interpret, document, and modernize legacy code, and (2) generating and validating equivalent implementations across multiple programming languages.

## Learning objectives

### Legacy Code Interpreter

By the end of this project, you'll be able to:

- Analyze unfamiliar legacy code with the support of AI tools
- Translate complex code into plain English explanations
- Identify risks and sources of technical debt
- Propose modernization strategies such as refactoring, rewriting, or migration
- Generate documentation and tests for legacy systems
- Reflect on AI's usefulness in maintaining and modernizing legacy code

### Multi-Language Code Generator

By the end of this project, you'll be able to:

- Define cross-language specifications with inputs, outputs, and test cases
- Implement a reference algorithm with clear, verifiable tests
- Translate implementations across at least three languages using AI
- Validate functional equivalence with automated tests
- Benchmark performance across language versions
- Document translation strategies, idioms, and common pitfalls


!!! tip
    For both projects, treat AI as a starting point—use it to accelerate analysis and generation, but always validate the output against the original intent, expected behavior, and quality standards.


!!! warning
    AI-generated translations and explanations can miss context-specific logic—always cross-check against tests, edge cases, and domain knowledge before treating output as correct.
