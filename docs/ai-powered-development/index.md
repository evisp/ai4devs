Use AI inside your development workflow to move faster, reduce friction, and turn assistance into consistent daily practice.

!!! note
    In this block, you will build two practical skills: (1) using AI Agents, such as Copilot to speed up real development work, and (2) integrating AI support into your IDE workflow so it becomes part of how you code every day.

## Learning objectives

### Copilot Productivity Sprint

By the end of this project, you'll be able to:

- Use Copilot to accelerate common development tasks with clearer intent
- Apply prompting patterns that improve code suggestions and reduce rework
- Use AI support for explanation, refactoring, and implementation planning
- Recognize when to accept, adapt, or reject generated output
- Build faster feedback loops while keeping quality under control

### IDE Workflow Integration

By the end of this project, you'll be able to:

- Integrate AI assistance into your daily IDE-based development flow
- Use AI support during coding, debugging, navigation, and code review
- Reduce context switching between tools, tabs, and disconnected steps
- Create a smoother workflow for testing ideas and refining code
- Work more consistently with AI as part of real development practice

!!! tip
    For both projects, focus on repeatable habits—use AI to support your workflow, but always verify output, intent, and code quality before moving ahead.

!!! warning
    Never confuse speed with correctness—faster suggestions are useful only when they are reviewed, tested, and aligned with the problem you are solving.
